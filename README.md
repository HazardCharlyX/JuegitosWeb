# 🕹️ Colección de Juegos Shitpost Web

Colección de minijuegos web cómicos, experimentales y adictivos desarrollados con **Vanilla HTML5, CSS3 y JavaScript moderno** (0 frameworks, 0 dependencias externas pesadas).

Desplegable directamente en **Vercel**, GitHub Pages o cualquier servidor web estático.

---

## 🎮 Catálogo de Juegos

### 1. 🌀 Fidget Spinner Pro Max 3000
- **Físicas Rotacionales Reales**: Inercia angular, fricción configurable y detección de arrastre y flick con ratón y pantalla táctil.
- **Audio Procedimental**: Sintetizador con Web Audio API que modula el pitch según las RPM y reproduce clics mecánicos, soplidos y boom sónico.
- **6 Skins absurdas en SVG**: RGB Gamer 3000, Doge Spinner, Pollo Chillón, Sierra del Apocalipsis, Ventilador de Abuela y Fidget de los Dioses.
- **Mejoras Shitpost**: WD-40 (fricción 0), Turbo V8, Soplido Cósmico, Freno de Mano y Modo Rave.

### 2. 🐉 Pokémon Edición Esmeralda (GBA Online)
- **Emulador Game Boy Advance Completo**: Basado en el motor IodineGBA en JavaScript puro.
- **ROM Oficial en Español**: Pokémon Edición Esmeralda (16 MB) preinstalada y lista para jugar.
- **Chasis GBA "Rayquaza Emerald Edition"**: Carcasa verde translúcida interactiva con cruceta D-Pad, botones A, B, L, R, Select, Start y LED reactivo.
- **Herramientas**:
  - ⚡ **Modo Turbo (2.8x)**: Avance rápido con la barra espaciadora.
  - 💾 **Exportar/Importar partidas `.sav`**: Compatible con mGBA, VisualBoyAdvance y emuladores móviles.
  - 📁 **Cargar ROMs personalizadas**: Arrastra o selecciona cualquier archivo `.gba`.

## 🕹️ Controles de Teclado (GBA)

| Botón GBA | Teclado |

| **START** | `Enter` |

| **Gatillo L** | `Q` o `1` |
| **Gatillo R** | `E` o `2` |
| **Modo Turbo** | `Espacio` |

## 🚀 Despliegue en Vercel

Este proyecto es 100% estático. Para desplegar en Vercel:
1. Conecta tu repositorio de GitHub en [Vercel](https://vercel.com).
2. Deja el Framework Preset como **"Other"**.
3. Haz clic en **Deploy**. ¡Listo en segundos!
